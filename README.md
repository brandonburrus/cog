# cog

An MCP server that gives AI agents persistent, semantically searchable memory. Memories are stored as local markdown files and indexed in Pinecone for vector search, with embeddings generated by Ollama.

## How it works

1. An agent calls `create-memory` with a name, description, keywords, and content
2. Ollama generates an embedding vector for the memory
3. The vector is upserted into Pinecone; the full content is written to a local markdown file
4. Later, `search-memory` embeds a natural language query and retrieves the most relevant memories by cosine similarity
5. `retrieve-memory` fetches a specific memory by name via the `memory://` resource template

## MCP tools

| Tool | Description |
|---|---|
| `create-memory` | Save information, strategies, patterns, and insights for future reference |
| `retrieve-memory` | Fetch a specific memory by name |
| `search-memory` | Semantic search across all memories by natural language query |

## Prerequisites

- [Bun](https://bun.sh) — runtime and package manager
- [Ollama](https://ollama.com) — local embedding model server
- [Docker](https://docker.com) — for the local Pinecone emulator (development / testing)

## Setup

### 1. Install dependencies

```sh
bun install
```

### 2. Pull the embedding model

```sh
ollama pull qwen3-embedding:8b
```

### 3. Configure environment

Create a `.env` file in the project root (Bun loads it automatically):

```sh
PINECONE_API_KEY=pclocal
```

The following variables are optional and show their defaults:

| Variable | Default | Description |
|---|---|---|
| `MEMORY_PATH` | `~/.config/opencode/memory` | Directory where markdown memory files are stored |
| `PINECODE_INDEX_NAME` | `cog-memory` | Pinecone index name |
| `OLLAMA_EMBEDDING_MODEL` | `qwen3-embedding:8b` | Ollama model used for embeddings |
| `MEMORY_SEARCH_SCORE_THRESHOLD` | `0.7` | Minimum cosine similarity score for search results (0–1) |

### 4. Start the local Pinecone emulator

The emulator must be configured with the correct vector dimension to match the embedding model (`qwen3-embedding:8b` produces 4096-dimensional vectors).

```sh
docker run -d \
  --name pinecone \
  -p 5081-6000:5081-6000 \
  -e PORT=5081 \
  -e PINECONE_HOST=localhost \
  -e DIMENSION=4096 \
  pinecone:latest
```

### 5. Install in OpenCode (or any MCP client)

Add the following to your MCP client config (e.g. `opencode.jsonc`):

```jsonc
{
  "mcp": {
    "cog": {
      "type": "local",
      "command": "bun",
      "args": ["--cwd", "/path/to/cog", "src/mcp.ts"],
    }
  }
}
```

## Development

### Run tests

Tests hit the real local Pinecone instance at `http://localhost:5081` and write markdown artifacts to `tests/.artifacts/`. Ensure the Docker container is running first.

```sh
bun test
```

### Type-check

```sh
bun run build
```

### Lint / format

```sh
bun run biome
```
